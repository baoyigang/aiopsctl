## 结论与适用范围

在**回环地址、隔离合成数据、单机演示**范围内，本轮未发现尚未修复的 P0/P1 阻断问题。发现的输入边界和指标展示问题已修复并独立复验。此结论不是生产安全认证，也不是企业 Elasticsearch 或 Oracle 接通证明。

应用没有生产身份认证、用户角色或租户级授权。`spaceId` 是配置的逻辑分组：列表筛选及实体引用必须同空间，但按实体 ID 的详情路由可以读取其他空间的实体，不能将空间切换器描述为 RBAC 或数据隔离。`X-Hengchuan-Write` 和 Origin 检查用于限制其他网站发起写入，不是登录凭证；本机进程能够构造合法请求。`demo-operator` 是演示标签，不是经过认证的操作人或不可抵赖的审计身份。公开部署必须另行设计认证、授权、审计及部署边界。

## 已核对的边界

- **输入及引用**：请求体限制 160 KiB，导入仅接受声明的单大屏格式及版本，导入大小另限 128 KiB；服务端生成新 ID，再执行整个候选快照的长度、数量、枚举、有限数值、重复名称和引用校验。指标—业务、事件—业务、大屏—业务/指标引用要求同空间。JSON 不是执行脚本或查询 DSL 的入口。
- **原子性与持久化**：[AtlasStore.cs](../backend/Hengchuan.Api/AtlasStore.cs) 第 102–136 行在写事务内检查 revision，对隔离副本变更及全量验证后，执行附 revision 条件的参数化更新，检查受影响行数后提交。无效候选、冲突和提交前取消不会保存半成品。删除仍被引用的实体要求先显式解除引用。
- **取消和重复操作**：前端读请求使用 AbortController 和代次编号，取消或过期结果不能覆盖新结果；变更封装阻止同时重复提交，409 保留草稿并要求显式刷新版本。取消网络请求不保证撤回已经提交的写操作；发生连接中断后应重新读取 revision 与实体确认结果，不能把“页面取消”宣传为事务补偿。
- **XSS**：审阅范围未发现 `v-html`、`innerHTML`、eval 或将导入文本作为命令执行；用户文本经 Vue 插值/SVG 文本显示。存在 CSP、nosniff 和 frame 限制。文本校验不是完整 HTML 消毒器，安全性仍依赖继续保持文本渲染边界，不能后续直接改成原始 HTML。
- **回环与浏览器写入**：[Program.cs](../backend/Hengchuan.Api/Program.cs) 第 29–38 行要求回环客户端及允许 Host，写 API 必须携带固定请求头，非空 Origin 必须同源或本地开发端口；CORS 只允许两个本地 Vite 来源。独立 Host/Origin/请求头反例均为 403。源码检查和回环测试不等于对云平台防火墙、反向代理或公网不可达性的全面实测；启动仍应绑定回环地址。
- **统计口径及空态**：可用性使用窗口内停机区间并集，当前自然窗口截至当前时间；无有效窗口/采样时不伪造数值。MTTR/MTBF 按本项目契约所述的窗口裁剪与事件计数口径计算，并非对企业全部事件采集完整性的保证。对比缺覆盖、单图 ES 失败和未接通来源均有可见状态。
- **ES**：[ElasticsearchAdapter.cs](../backend/Hengchuan.Api/ElasticsearchAdapter.cs) 由服务端固定索引/服务/环境/指标映射白名单及固定查询模板限制范围；HTTP 重定向关闭，非回环连接要求 HTTPS，URL 不接受 userinfo/query/fragment，响应有大小/深度/超时限制。查询前验证精确索引和字段类型；超时、分片失败、异常桶及非有限值明确报错，ES 查询失败不回退合成成功值。`raw` 不支持会明示，不把聚合结果充作原值。服务器配置者本身仍是可信角色，此适配器不是对任意管理员配置地址提供的通用 SSRF 沙箱。
